Meteor pass recorder

Russia's Meteor-M satellites send weather pictures as LRPT: digital QPSK, 72,000 symbols a second, about 120 kHz wide. Start the dongle a minute before the pass, press record, and stop when it sets. You get an IQ file to decode into a picture. Pass times are on the repeaters page; how LRPT works is chapter 21.

Start the dongle, then record. The signal is a flat-topped hump between the yellow lines, sliding a few kHz with Doppler.

    Turning it into a picture

    • Open the file in SatDump: Offline processing → METEOR M2-x LRPT 72k, baseband format cu8, sample rate from the file name. It demodulates, Viterbi-decodes, de-randomizes and decodes Meteor's JPEG into the visible and infrared channels.
    • Antenna: a V-dipole (two 53 cm rods at 120°, horizontal, outdoors) beats anything on a windowsill. Passes under 20° rarely decode.
    • Files are about 30 MB a minute and stay in this tab until you save them.
