Just enough code

Every lesson on this path has code you can run and change. This lesson teaches exactly what you need to read it: numbers, names, lists, loops and functions. No installing anything: each box runs right here in the page. Change things, break things, press Reset to get the original back. By the end you'll compute a model's error yourself.

The code is JavaScript, the language every web browser speaks. At work, ML is mostly written in Python; stage 4 switches over, and section 7 shows how little changes.

1. The computer as a calculator

print(...) shows whatever you put between the brackets. Separate several things with commas. * is times, / is divide, ** is "to the power of", and text goes in quotes. Lines starting with // are comments: notes for people, ignored by the computer.

Use the box: what is \(3^{10}\)? (Change a line to print(3 ** 10) and run.)

59049. You'll see ** for powers, and Math.sqrt, Math.exp (\(e^x\)) and Math.log (\(\ln x\)) all over the path.

2. Names for values

A variable is a name for a value, so you can use it later. const makes a name that never changes; let makes one you're allowed to change. = doesn't mean "equals" here, it means "from now on, this name holds this": so x = x + 1 is fine, it means "x becomes one more than it was".

Without running it: what does this print? let a = 5; a = a * 2; a = a - 3; print(a);

\(a\) is 5, then \(5 \times 2 = 10\), then \(10 - 3 = 7\). Each line uses the value the line before left behind. Paste it into a box to check.

3. Lists

ML is about many examples at once, so you'll constantly hold lists of numbers. In JavaScript a list is an array, written with square brackets. Items are numbered from 0: the first item is xs[0]. xs.length is how many there are, and xs.push(v) adds one to the end.

For const xs = [4, 8, 15, 16, 23, 42], what is xs[4]?

Counting from 0: xs[0] = 4, xs[1] = 8, xs[2] = 15, xs[3] = 16, xs[4] = 23. Counting from zero trips everyone up at first.

4. Loops: do it for every item

A loop repeats code. for (const x of xs) runs the block in curly braces once per item, with x being each item in turn. for (let i = 0; i < n; i++) counts: start i at 0, keep going while i < n, add 1 each time (i++). Adding things up in a loop is the most common pattern in this whole path: the mean, the error, the gradient.

Change the box to add up the squares \(1^2 + 2^2 + \dots + 10^2\). What is the total?

385. One way: let s = 0; for (let i = 1; i <= 10; i++) s += i * i; print(s);. In math this is written \(\sum_{i=1}^{10} i^2\): the big sigma is a loop.

5. Functions: name a recipe

A function takes inputs and gives back an output, exactly like a function in math. The short form (x) => 2 * x + 1 means "given x, give back 2x + 1". For longer recipes, use curly braces and return. A model is a function: input in, prediction out.

If const g = (x) => x * x - 3, what is g(4)?

\(4 \times 4 - 3 = 13\).

You'll also meet two shortcuts that do a loop for you. xs.map((x) => x * 2) makes a new list with the function applied to every item, and xs.reduce((s, x) => s + x, 0) walks the list carrying a running total (starting at 0). They do exactly what the loops above do, in one line.

6. Putting it together: a model's error

Six taxi rides, each a pair [km, minutes]. The model guesses a × km + b. The mean squared error, from the last lesson, is: for every ride, take guess minus truth, square it, add them all up, divide by how many. Here it is in code, and two helpers that every page uses: table(rows) shows a table and plot(numbers) draws a line chart.

Run the box. With \(a = 2.5\) and \(b = 6\), what is the mean squared error? Then try other values of a and b and see if you can get it lower.

0.958: the squared errors are 0.25, 0, 0.25, 0.25, 1 and 4, which add up to 5.75, divided by 6. The plot is the error as you turn the knob \(a\): a valley. Training means finding the bottom of that valley without trying every value, which is what stage 1 is about.

7. The same thing in Python

From stage 4 on, you'll also write Python, the language ML teams use. The ideas are identical; the spelling changes a little:

const a = 2.5;a = 2.5

Python uses indentation instead of curly braces, and no semicolons. With NumPy (stage 4) most loops disappear entirely: the mean squared error becomes one line, np.mean((a * km + b - minutes) ** 2).

8. What to carry forward

  • const / let name values; = means "becomes".
  • Arrays hold lists of examples, counted from 0; for (const x of xs) visits each one.
  • Adding up inside a loop is the pattern behind means, errors and gradients; \(\sum\) in a formula is a loop in code.
  • A function is a recipe from inputs to an output, and a model is a function.
  • Every code box has print, table and plot, and you can always Reset.
