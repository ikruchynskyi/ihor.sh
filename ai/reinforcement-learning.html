Reinforcement learning

Every model on this path learned from examples with answers. Some problems have no answers to copy, only consequences: a game won or lost many moves later, a robot that stays upright or falls, a chatbot reply that people rate up or down. Reinforcement learning (RL) learns from consequences: an agent acts, the world responds with a reward, and over many tries the agent learns which actions lead to more reward in the long run. It's how AlphaGo learned Go and part of how chat models learned to be helpful (RLHF). This lesson builds the core ideas on a small city grid you can watch learn.

1. Agent, state, action, reward

At each step the agent sees a state \(s\), picks an action \(a\), receives a reward \(r\) and lands in a new state. Its goal is the return: the sum of future rewards, each step further away worth a factor \(\gamma\) (gamma, the discount, a little under 1) less:

\[ G_t = r_{t+1} + \gamma\, r_{t+2} + \gamma^2 r_{t+3} + \dots \]

The grid below: a rider starts top-left and must reach the station (green, +10). Every step costs −1 (time), the red cells are construction (−5), and the street is slippery: 10% of the time the rider moves in a random direction instead. Nothing tells the agent where the station is; it has to find out.

An agent learns from rewards that may arrive many steps after the action that earned them, aiming for the most discounted reward in the long run.

2. Values, and the Bellman equation

The value of a state is the return you can expect from it if you act well from then on. The key fact: a state's value is the best action's immediate reward plus the discounted value of where it leads. That's the Bellman equation, written with \(Q(s, a)\), the value of taking action \(a\) in state \(s\):

\[ Q(s, a) = \mathbb{E}\left[ r + \gamma \max_{a'} Q(s', a') \right] \]

The colors in the grid are \(\max_a Q(s, a)\) as the agent has learned them, and the arrows the best action from each cell. Watch the values spread outward from the station like a rumor: first its neighbors learn they're close, then their neighbors.

With \(\gamma = 0.9\), a step costs −1 and from the next cell the best you can do is worth 0. What is this step's \(Q\)?

\(-1 + 0.9 \times 0 = -1\). If the next cell were worth 10: \(-1 + 0.9 \times 10 = 8\). Values are built from the rewards ahead, discounted.

A state's value is its best action's reward plus the discounted value of where that action leads: a recursion that lets value flow backward from rewards.

Why the Bellman equation holds
  1. The return from now is the next reward plus the discounted return from the next step on: \(G_t = r_{t+1} + \gamma G_{t+1}\) (factor \(\gamma\) out of every later term).
  2. Take expectations: \(Q(s, a) = \mathbb{E}[G_t \mid s, a] = \mathbb{E}[r_{t+1} + \gamma G_{t+1} \mid s, a]\). The expectation covers the slip: where you land is random.
  3. If from the next state you act as well as possible, the expected \(G_{t+1}\) is the best \(Q\) there: \(\max_{a'} Q(s', a')\).
  4. So \(Q(s, a) = \mathbb{E}[r + \gamma \max_{a'} Q(s', a')]\). The values must agree with themselves one step later; that self-consistency is what Q-learning drives toward.
  5. With \(\gamma < 1\) a reward \(k\) steps away counts \(\gamma^k\): at 0.95, a reward 50 steps away counts 0.077 as much. Lower \(\gamma\) makes the agent short-sighted; try 0.5 in the grid.

3. Q-learning: learn values from your own steps

The agent doesn't know the rules of the world (the slip, where the station is), so it can't solve the equation directly. Q-learning nudges its estimate after every single step toward what that step suggests:

\[ Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right] \]

The bracket is the surprise (a "temporal difference" error): what happened plus what's expected next, minus what was expected now. Chapter 2's gradient step, toward a target the agent keeps improving. And it must explore: with probability \(\varepsilon\) take a random action, otherwise the best known one, or it never discovers a better route than the first one it found. In the practice notebook a coffee cart worth +3 sits two steps from the start and the far corner is worth +20: with ε = 0.1 the agent settles for the coffee in all six runs; with ε = 0.5 it finds the corner in all six, after 2,000 episodes. Exploration is necessary, and expensive.

Q-learning moves each estimate toward the reward it just got plus the best estimate of the next state, and explores a little so it can find better paths.

4. Policy gradients, deep RL, and RLHF

A table of \(Q\) works for 48 cells, not for a robot's joint angles or a game screen. Two ways to scale:

  • Deep Q-networks replace the table with a network that maps a state to the \(Q\) of each action (DeepMind's Atari player, 2015).
  • Policy gradients skip values: a network outputs action probabilities directly, and after each episode, actions that came before a high return are made more likely: the gradient of \(\sum \log \pi(a_t \mid s_t)\) weighted by the return. In the practice notebook this method (REINFORCE) teaches a network to balance a pole on a cart, from falling after a few dozen steps to the 500-step maximum within about 150 tries. PPO, a steadier version, trains most robots and the RL step of chat models.

RLHF (reinforcement learning from human feedback) is the last one at scale: people compare pairs of model answers, a reward model learns to predict their preferences (the evaluating-LLMs lesson's pairwise judging), and the language model is tuned with PPO to produce answers the reward model scores highly.

Why does a pure policy-gradient agent need many episodes even on a simple task?

  • Its network is too large
  • It learns only from whole-episode returns, which are noisy: a good action in an unlucky episode gets blamed with the rest
  • It never explores
Credit assignment with noisy returns needs many samples to average out (C4's 1/√N). Baselines (subtracting the average return) and learned value estimates (actor-critic, PPO) reduce the noise.

To scale, networks replace the table: deep Q-networks predict values, policy gradients make rewarded actions more likely, and RLHF tunes chat models toward human preferences.

Where it breaks: RL gets exactly what you reward
  • Reward hacking. In a well-known OpenAI experiment, a boat-racing agent rewarded for hitting targets learned to circle a lagoon forever, catching fire and crashing, scoring more than any finisher and never finishing the race. Agents optimize the reward as written, not as meant. RLHF has the same risk: a chat model can learn to please the reward model (long, confident, flattering) rather than to be right.
  • Sparse rewards. If the only reward is at a distant goal, random exploration may never reach it, and nothing is learned. Make the grid's station farther and walled off, and watch learning stall; shaping (small rewards for progress) helps but can itself be hacked.
  • Instability. The targets move as the agent learns, and its own actions decide what data it sees. Deep RL runs are notoriously sensitive to seeds and settings (the experiments lesson's seed lottery, much worse).
  • The real world is slow and costly. The notebook's pole needs 150 tries; a real robot can't fall 150 times an hour. Most robotics trains in simulation and then fights the gap to reality.

5. What to carry forward

  • Agent, state, action, reward; the goal is the discounted return.
  • Bellman: \(Q(s, a) = \mathbb{E}[r + \gamma \max Q(s', \cdot)]\); values flow backward from rewards.
  • Q-learning: a step toward the temporal-difference target; explore with ε.
  • Policy gradients raise the probability of actions before high returns; PPO and RLHF build on them.
  • The agent optimizes the reward you wrote: design it, and watch for hacking.
