How this works

A small job on the server fetches the MTA's public feeds every 5 minutes: subway alerts and elevator and escalator outages. Each alert and outage is stored once with the first and last time we saw it, so "how long did it last" is accurate to about 5 minutes. Gaps happen when the server or the feed is down; the poll log keeps track of them.
